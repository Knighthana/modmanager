## 六、架构最终状态

```
dispatch(TaskRequest)
  │  ├─ resolver_type + resolver_args → SourceDescriptor
  │  └─ output_type + output_args → DestDescriptor
  │
  ├─ Resolver.resolve() → SourceDescriptor（纯解析）
  ├─ DataPort.fetch(SourceDescriptor, intent) → clean dicts
  ├─ Engine.compute() / fileops.execute()
  └─ DataPort.push(DestDescriptor, intent, result)

orchestrator/
├── __init__.py         ← dispatch()
├── entry.py            ← Intent, TaskRequest
├── resolver.py         ← 纯解析（SourceDescriptor）
├── data_port.py        ← fetch() + push()（唯一 I/O）
├── verifier.py         ← 规则校验
├── compute_pipeline.py ← compute(data: dict) -> dict
└── fileops/
    ├── __init__.py      ← execute()
    ├── _common.py       ← _notify
    └── planner/
        ├── planner.py      ← plan_fileops() + check_backup_gate
        ├── preflight.py    ← 门禁检查
        └── ignore_rules.py ← .kmmignore 解析
```
